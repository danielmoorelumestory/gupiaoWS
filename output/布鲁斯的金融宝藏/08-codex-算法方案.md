# 息差算法：本轮锁定规格与另外三条路线的取舍

日期：2026-11-10。讨论者：Codex。

**我的选择：本轮只测试一个“AR(1)校准的指数加权通道”，不采用随机游走中轨加AR(1)偏离的双状态模型。每年年初用截至上年末的息差、以扩展历史条件极大似然估计一个日频持续性系数φ，固定该年指数权重为φ的幂；中轨与尺度均为同一组权重下的均值和总体标准差。阈值保留2，主比较仍是原z与新z在同一反转控制下的120日股债相对收益样本外MSE差。**

这里的“只测试一个”是约束研究者自由度，不是说这个方法有成功保证。算法更多，并不自动增加经济信息；A、C、D、E未通过后，新的历史检验仍属于连续探索，不能重新宣称整段历史未被看过。

我只检查了息差自身的参数和数值公式，**没有生成新指标的未来收益表，没有比较其事件收益或预测MSE**。检查脚本与输出为 `replica/research/codex_algorithm_diagnostics.py`、`codex_algorithm_diagnostics.txt`，只读取日期和息差；日历文件仅读取日期列。

## 一、先纠正提出问题时的三个前提

### 1. 750日窗口和AR(1)半衰期不能直接比较

半衰期描述一次冲击的条件期望衰减速度；750日窗口描述一个估计器纳入多少历史观察。这不是同一种长度。矩形750日权重的平均年龄约374.5日。无限历史指数权重若取 `φ=(750−1)/(750+1)`，也有同样平均年龄，且权重有效样本量 `(1+φ)/(1−φ)=750`，对应的**权重半衰期约259.9日**。

这里的权重有效样本量不是独立经济样本数，序列相关后两者更不同。上述换算只是说明：不能因为估出167日、533日或856日半衰期，就断定原750日一定错了，更不能据此直接将窗口换成相同数值。

你按2005—2012、2013—2019、2020—2026切段，能描述估计值差异，但分段本身、单位根附近的估计误差和制度变迁都会影响结果；点估计差异还不是“均值回复速度发生显著变化”的正式证据。本轮禁止把这些分段边界变成模型的重置年份。

### 2. 双状态模型不是处处不可识别，但本样本很容易弱识别

草案若写成：`s_t=μ_t+x_t`，`μ_t=μ_(t−1)+η_t`，`x_t=φx_(t−1)+ε_t`，并假设两种扰动独立，严格 `|φ|<1`、参数在内部时，不应笼统说理论上完全不可识别。

但它的有限样本识别依赖很弱的差分自协方差信息。设x平稳方差为V，则对k≥1：

`Cov(Δs_t,Δs_(t−k)) = −V(1−φ)²φ^(k−1)`。

当φ接近1，这部分可区分信息很小；极限中两项都趋近随机游走，只能识别合计扰动，难以把慢变化分配给“中轨”还是“偏离”。再加测量噪声、相关扰动或不同初值，就多出一批选择空间。单侧滤波解决前视，不解决这种识别问题。

此外，`滤波x / x的平稳标准差`并不是自动方差为1的z。滤波条件均值会受到状态不确定性的收缩；不同参数分解可能改变收缩程度和触2频率，虽然画面依然很好看。不能只说“仍用2，所以没有调阈值”。

### 3. 拟合息差形状不等于预测股债收益

让滤波残差更白、尾部更像正态、模型似然更高，最多说明对息差本身的描述改善。若股债相对收益预测不改善，它不是已经成功的估值优化。反过来，模型正常运行也不要求通道读数必须是标准正态。

## 二、第1条唯一锁定方案：AR(1)校准的指数加权通道

### 1. 模型用途与参数边界

只拟合观测到的息差：

`s_t = c + φ s_(t−1) + ε_t`。

按日频条件高斯似然估计，等价于含截距的一阶OLS；若真实创新不服从正态，则把它理解为高斯准似然的校准规则，不宣称数据已被证明正态。条件MLE/OLS的对应关系见[statsmodels官方文档](https://www.statsmodels.org/stable/generated/statsmodels.tsa.ar_model.AutoReg.html)。

这个模型只给指数权重提供**一个**持续性系数，不拟合两个潜在状态，不把拟合常数均值称为随时间变化的真实公允中轨。把AR冲击持续性用于平滑权重是透明的算法约定，并非由资产定价或最优滤波定理唯一推出；本轮正是要检验这个约定有没有增益。

允许参数为 `0<φ<1`，创新方差须为正且有限。**不截到0.95/0.999，不限制半衰期上下界，不尝试二阶AR、变点、OU局部窗口、不同衰减映射或卡尔曼替代版。** 若某个应运行年份估计落在边界外、设计矩阵退化或尺度非正，该年标为算法不可用；本轮主候选记“可用性未满足”，不得删掉该年后宣布成功，也不得偷偷用上一年参数、原750日或优化器边界兜底。软件故障可以修复；统计参数不满足假设不是软件故障。

### 2. 数据、日历、估计起点

- 息差使用现有日频原值，单位百分点，不先差分成新指标，不换估值聚合口径。日历沿用v2核对后的沪深300价格交易日历。
- 年度参数只用当年1月1日之前的原始息差；首次须有至少五个日历年的历史跨度。因此本数据**首次在2011年年初估计**，2011年第一个交易日起才发布新z；不从未来补算2006年的新z。
- 每年只重估一次，扩展使用全部既有历史，不按估计半衰期反过来截训练窗口。五年是与原预测训练约定一致的最低操作长度，并非保证识别精确的定理；不再比较三年、八年、十年择优。
- 原始息差缺失日不当成新观测，不在AR估计中插入平盘。估计只用真实交易日历上**相邻两日都存在原值**的一日转移；跨缺口的两点不能冒充一个一日滞后。这里是有效一日转移的条件似然，不宣称已做缺失数据的完整观测似然。
- 新z缺失日沿用最后一个已正式发布的新z，表示没有新估值信息；原z沿用v2既有口径。不得用未来插值修补，需保留“真实观测/沿用”的标记。

AR条件MLE使用闭式解，不需要优化器或多起点。对有效一日对 `(a_i,b_i)`：

`φ = Σ(a_i−a均值)(b_i−b均值) / Σ(a_i−a均值)²`；`c=b均值−φ a均值`；`q=平均(b_i−c−φa_i)²`。

`q`按MLE分母N，作为模型诊断记录，不引入新的残差波动模型。半衰期为 `−ln(2)/ln(φ)`，仅展示，不作另一次四舍五入窗口。稳定数值计算可使用 `log1p(φ−1)`，不能改变估计值。

### 3. 中轨、尺度与新z：同权重的有限历史总体矩

该年度固定φ后，在日历位置t，对所有已知真实观测i≤t，取 `w_i=φ^(t−i)`：

`m_t = Σw_i s_i / Σw_i`；

`v_t = Σw_i(s_i−m_t)² / Σw_i`；

`z_new,t = (s_t−m_t)/sqrt(v_t)`。

**尺度取指数加权总体标准差，不用潜在x的平稳标准差，也不用一步预测创新标准差。** 这样新旧仍都在比较“当前息差相对自身历史位置”；如果改成一步创新，测的会更接近当天意外变动，而不是估值偏离。中轨和尺度都用同一个φ，不能让尺度另外选衰减速度、MAD或分位数。本轮测试的是整套指数权重通道，不声称能独立识别中轨与尺度各自贡献。

公式使用当日收盘值，之后下一交易日收盘起评价，时点与原z一致。总体矩不做额外无偏修正，与原 `ddof=0` 的约定一致。2只是原有描述阈值，不承诺相同尾部概率。

稳定递推如下，避免 `E[s²]−E[s]²` 的相消；每个交易日先衰减旧权重，有新观测才加入：

```text
W = 0; m = 0; M2 = 0
for each trading day:
    W = φ * W
    M2 = φ * M2
    if raw spread exists:
        W = W + 1
        delta = s - m
        m = m + delta / W
        M2 = M2 + delta * (s - m)
        v = M2 / W
        # 只有进入正式发布年份且v>0，才记录当日z
        z = (s - m) / sqrt(v)
    else:
        # 不补造观测；m和v不变，正式读数沿用上一个已发布z
```

每年年初用新φ**从最初历史逐日回放至上年末，只为初始化新年度的W、m、M2**，然后在本年在线更新。有限权重归一化避免另选初始均值、初始方差和burn-in长度；年度重估可能导致中轨跳变，这一点要展示，不额外平滑。历史已发布z永久缓存，**绝不能把新φ回放出的历史z覆盖旧年度特征，再拿覆盖值训练收益模型**。这会让历史训练特征使用较晚信息。

缺失日指数按交易日继续衰减，缺失日没有新的权重1；因此此处时间单位仍是交易日，不是把漏5天后的观测序号压成连续日。年初若缺失新观测，沿用上一已发布z直至有真实新值，仍记录其原发布时点。

### 4. 仅基于息差的可行性检查结果

按上述有效一日转移拟合，2011—2026年各次年初估计都满足 `0<φ<1、q>0`，没有数值上必须裁剪的问题。半衰期点估计约：2011年387日、2012年1,125日、2013年856日、2020年535日、2026年523日。它们是截至各年开始的估计，不是对应年份之后的结果。

这也说明扩展估计不会自动“发现最近几年167日”：旧制度数据仍然占权重。不得见到这个结果后改成最近七年估计、最近一段重置或挑更短半衰期。早期只有少数个估计半衰期的历史，参数不确定性仍大，五年不是免检证书。加权均值/方差递推已用独立的直接权重计算核对一致；尚未看任何新z的收益表现。

## 三、主检验与失败标准：实施前就定死

1. **目标、时点不变：** 沪深300全收益减中债国债7—10年财富收益，信号下一真实交易日收盘进入，持有120个交易日；完整月末取样，成熟日正确偏移121日。250日不是本轮用来救结果的替代主期限。
2. **比较对象只有一对：** `M_old=截距+过去250交易日价格收益+旧z`；`M_new=截距+同一反转收益+新z`。不把新旧z一起塞入，不加入正半轴截断、交互项、利率状态或其他指数。
3. **两模型训练完全同样的日期：** 只用2011年起实际发布的新z与可用旧z共同存在的月份；年初扩展训练、至少60个已成熟月度标签，两边都按这个共同集合拟合。原z不能额外享有2006年起更多训练标签。按当前覆盖，首次可评价年份应为**2017年**，程序需输出并核对，不为了扩样而下调60。新旧都不得拿此前v2的160个月MSE直接混比。
4. **主统计量：** 对每月配对误差计算 `d=e_old²−e_new²`，主效应为平均d。原样输出两个MSE、共同月数、起止日期。同期另列只含截距、只加反转的参考MSE；它们不是事后第二主检验，但能防止“比一个坏旧模型好一点”被误说成已有独立择时信息。
5. **推断原规格：** 循环区块自助法，主区块12个月，24个月仅敏感性；5,000次，随机种子分别1012、1024。成对抽d，不拼价格重造信号。双侧95%百分位区间与中心化零均值下的单侧尾部比例同时报告；尾部比例可使用有限重抽修正 `(1+次数)/(5001)`，不再叫参数后验概率。保持与v2一样的零假设方向。
6. **判定：** 均值d≤0，主检验失败；均值d>0但主12月区块双侧区间含0或中心化单侧比例≥0.05，记未证实。只有主区块下限>0且单侧比例<0.05，才记本轮相对旧表达改善；24月方向反转或区间含0，则加注长区块不稳健，不能称稳健通过。任何参数不可用年份不得被悄悄剔除，按前述可用性失败处理。
7. **多重比较与研究边界：** 本轮只新增这一个主比较；本轮内部不因为多展示一个诊断就再增加候选。若同时测试MAD、经验分位、其他φ映射或多个指数，须事先登记新的检验家族并作Holm校正，不许每个候选单开一个“唯一”检验逃掉选择偏差。即使本轮单一比较通过，既往大量历史探索仍存在，不能因此重新认定历史为真正未见样本外；冻结后新增日期才提供新的向前证据。
8. **事件仅描述：** 阈值仍z≥2、z≤−2，两边都用既有20交易日触发合并，再按实际进入与退出区间重叠连通分组；逐期限列成熟事件数、组数、事件等权均值及组等权均值，二者不得互换择优。旧与新采用相同共同评价起点；2017年前旧事件可单列背景，不能混成同一比较。输出逐组剔除，但不靠事件表推翻主MSE失败。

实施验收还应包含“前缀不变性”：将原始文件截到某个历史年末生成当年已发布特征，与完整文件在线生成的同段特征逐点一致；追加未来数据不能改变过去参数、z、模型预测。每年保存估计截止日、有效转移对数、φ、q、半衰期、每月特征发布时点和数据版本。这里不要求另开一批可调检验，只核对时点。

## 四、第2条：MAD与经验尾部，不宜紧接着当优化赛道

**判断：有诊断价值，作为下一项收益优化优先级最低。** 原通道用标准差不等于已承诺正态；`|z|≥2`有8.6%而非4.6%，既可能来自厚尾、偏斜、制度混合，也可能来自持续性和滚动标准化，不是一个隔离了其他因素的正态性检验。

MAD提高的是对极端观测的稳健性，不会自动把真正的盈利崩塌、金融危机或流动性冲击变成可删除噪声。`1.4826×MAD`中的常数本身就是为正态分布下与标准差对齐而定，见[NIST说明](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/mad.htm)。因此“MAD不需要正态，所以2就恢复了同样显著性”不成立。

如果把同样阈值2除以一个往往更小的尺度，触轨次数会变多，实际上也改变了有效触发门槛；这很可能又变成已经否掉的阈值优化。经验尾部则与此前试过的滚动分位数高度重合，不能换个“非参数”名称再开一遍选优。

建议本轮只附原z和新z各自的尾部占比、偏度、数据缺失/已知口径断点说明，不据此切换尺度、不删除危机样本。若未来独立研究稳健尺度，先定义是纠正供应商坏数据还是描述真实厚尾，并只登记一个方案；不能比较MAD、IQR、分位正态化后保留收益最高者。

## 五、第3条：在E/P上聚合方向正确，但首先是数据与经济权重问题

**判断：理论上比改均线外形更接近指标根源；拿不到历史时点数据，就不能补成同等可信的二十年回测。**

若使用相同利润/市值口径，市值加权 `Σw_i(E_i/P_i)` 等于组合总盈利除以总市值；而对个股PE做算术平均再求倒数没有这个恒等式。首先必须确认现有“加权PE”是否本来就是整体法；若已经是，改成E/P聚合可能只是代数改写，**新增操作实际只有截尾或缩尾**，不能把整个收益改善都归功于一个更先进的平均法。

还要区分：截尾是删除两端并重归一权重，缩尾是把两端值压到界限。两者不是同一方案，都要选择比例、权重、负盈利处理和成份覆盖。极低/负E/P可能是真实亏损，高E/P可能是真实周期利润，不能默认是测量异常；把它们处理掉改变了组合经济含义。标准5%/10%也不是天然公允的参数。用户不信中位数有道理，但不能用“截尾平均更数学”回避这组选择。

**没有完整历史成份时，诚实可做的事只有这些：**

- 从现在起保存当时成份、计算权重、公告可得的利润、市值与退市记录，只做当前横截面和今后验证；不能拿今天成份回填过去再叫历史指数。
- 只在能拿到可靠当时成份与财务时点的较短时期做试验，所有候选、基准都取同一短区间，明确有效行情数；不能把短期截尾结果接到旧整体指数上拼出“二十年优化”。
- 如有当时公开的基金持仓或固定起始股票池，可研究那个明确的代理组合，使用披露后才可知的持仓、保留后来退市股票，并承认它不是原沪深300；不得拿后来公布的持仓提前用于此前半年。
- 如果只能拿到现存股票的后复权历史，最多做“条件于今天幸存集合”的敏感性展示，不能作策略有效性、跨指数泛化或历史风险改善的证据。拿不到退市、亏损或历史权重，不能假装它们缺失是随机的。

也可以利用已有指数整体EY、财务披露与行业权重做口径审计，但无法仅凭指数PE、中位数PE两个数还原横截面的截尾E/P，不能编造一个等价替代公式。这条路的下一步是查数据覆盖与原聚合定义，条件未满足就停止，不立刻挑截尾比例。

## 六、第4条：贝叶斯适合表达不确定性，不适合把重合指数变成更多成功次数

**判断：值得做，优先作为不确定性说明，不能算新的盈利优化。** 它能清楚区分先验、似然和后验，让用户看到结论对先验与相关结构有多敏感；它不能增加宏观事件数量、洗掉选择偏差，或自动保证小样本可信。

7个重叠连通事件组也不必然彼此独立。直接给6/7成功套一个Beta后验，只在独立、同分布且事件选择规则已固定的简化下成立；不能把后验“成功概率”当成未来制度下的胜率。模型使用组收益还是事件收益、是否估基准超额、重尾如何处理，都应先固定，不能从若干先验中选后验最乐观的一个。

**高度重合的指数尤其不能仅靠分层均值池化处理。** 上证50、中证100、沪深300、中证800共享股票和政策行情；同一日期上的指数收益残差高度相关。一个只写“每指数自己的均值来自共同总体”、却在似然中当作独立观察的模型，会继续高估信息。

若以后实施，至少以共同宏观事件组为观测层、同组多个指数为相关向量，包含共同事件冲击；要么从可靠日频数据约束残差相关结构，要么只选一个代表指数进入主后验，其他作敏感性展示。七组不足以自由估计一大个协方差矩阵，分层并不会解决这种参数不足。中证100在2022-06有编制断点，必须明确前后统计对象改变，不能把变化都归给一个平稳指数随机效应。

建议先把现有单一300、原冻结事件规则的不确定性说明做好，采用至少一个偏保守与一个弱信息先验作并列敏感性展示、完整报告，不据后验挑规则。实际实施前再锁先验数值和相关结构；本轮没有同时启动这个模型，也没有计算任何有利后验。若只想表达“我们不确定”，现有事件组表和区块区间已经可以做到，不必等待贝叶斯软件。

## 七、顺序与向用户的解释

我的顺序是：**1作为唯一新算法试验；4作为不确定性表达，与它配套但不创造新信号；3先做数据与聚合定义审计，有合格时点数据才实施；2暂缓收益试验，只做诊断。** 第1条若失败，不按这个名单自动接着轮流搜出赢家；先报告失败，再决定是否另开有经济理由的新研究。

对用户可以这样说：

> 我们之前主要是在用滚动统计描述历史，现在会用一个固定的时间序列估计规则替代人为的有限窗口，并把年度估计、数据时点和失败标准事先写死。新算法仍只使用原来的息差信息，它能否预测股债相对收益，需要接下来的冻结检验回答；让曲线更平滑、残差更像正态或名字更复杂，都不算成功。
>
> 原指标在少数历史上轨事件上有较好的相对收益，但已做的系统预测和配置检验尚未证实稳健增量。我们不会因换成数学模型就把这个限制抹掉；只有在共同样本、正确时点和预定主检验下确有改善，才会把它叫作历史表达上的改进，真正的可靠性还需要后续新数据。

我不认为四条都应取消；我反对把它们合成一个大模型再挑参数。本轮上述第1条已经足够具体，可以直接实施，并且明确允许它失败。
