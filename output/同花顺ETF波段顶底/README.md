## 核心计算

```text
N:=13;
LC:=REF(CLOSE,1);
波段值:100*SUM(MAX(CLOSE-LC,0),N)/SUM(ABS(CLOSE-LC),N);
```

- 使用最近 **13 次收盘价变化**，需要 14 个收盘价。
- 使用价格差（元），不是每日百分比收益率。
- `SUM` 为等权滚动求和，不能替换成递推 `SMA`。
- 高位线 70（绿），低位线 30（红）；低于 30 画红柱，高于 70 画绿柱，柱体从阈值线画到波段值。
- [同花顺绘图公式文本](formulas/同花顺_复现公式.txt) 的柱宽仅为近似，未经同花顺编译实测。

令上涨变化之和为 U、全部变化绝对值之和为 A，则 `V=100*U/A`。
它也等于 `50+CMO(13)/2`，或 `50*(1+(C-REF(C,13))/A)`。
标准 Kaufman ER 取净变化的绝对值，丢失方向，不能直接替代这里的带符号比值。

## 项目中的调用方式

计算和数值复验均只需 Python 标准库，不联网、不安装依赖。
在仓库根目录运行：

```sh
python3 output/同花顺ETF波段顶底/verify.py

python3 output/布鲁斯的金融宝藏/replica/bruce_replica/etf_band.py \
  --input output/同花顺ETF波段顶底/evidence/tencent-588060.json \
  --symbol sh588060 \
  --output /tmp/etf-band.csv

# 解释为什么价格下跌、指标却回升；可同时保存CSV或JSON
python3 output/布鲁斯的金融宝藏/replica/bruce_replica/etf_band.py \
  --input output/同花顺ETF波段顶底/evidence/tencent-588060.json \
  --explain
```

在 `output/布鲁斯的金融宝藏/replica/` 中也可以：

```sh
python3 -m bruce_replica.etf_band \
  --input ../../同花顺ETF波段顶底/evidence/tencent-588060.json
python3 -m unittest discover -s tests -p test_etf_band.py
```

Python 调用：

```python
from bruce_replica.etf_band import etf_band

values = etf_band(df["close"])  # 按时间升序，返回与输入等长的 list
df["etf_band"] = values
```

输入支持腾讯日线原始 JSON、含 `rows`（每项含 `date/close`）的 JSON、或含 `date/close` 列的 CSV。
日期必须严格升序，价格必须为有限正数；`None` / CSV 空值会中断窗口。
CLI 默认打印最后一根读数，`--output` 可保存全序列；CSV 的 `value` 保留计算精度，`display_value` 才保留三位小数。
计算函数支持自定义周期，但只有默认 13 周期经过本次核验。

## 变化解释与规则标记

`--explain` 或 Python 的 `explain_rows(rows)` 增加解释字段，原来的 `value` 不变：

- `incoming_change` / `outgoing_change`：当前进入和移出窗口的价格变化。
- `expiry_contribution_points` / `incoming_contribution_points`：先移出、再加入的固定顺序分解，单位为指标点。它不是唯一因果归因；中间零分母时返回空值，不填造贡献。
- `normalized_close_movement`：`A/(13*C)` 的归一化收盘波动尺度，不能当作ATR或收益率标准差。
- `mechanism`：例如“价格未涨而指标回升，移出项占优”。
- `cross_below_30` / `cross_above_30` / `cross_above_30_price_up`：研究用事件标记，不是已经验证有效的买卖指令。

[完整解释示例](examples/588060-20261113-explained.json) 的末根：移出项贡献约 `+6.209` 点，当前价格贡献约 `-2.941` 点，合计 `+3.269` 点。最后仍显示 `53.115`。

固定规则的方案、原始输入、分红/份额口径、事件表和离线复算方法见 [研究目录](research/固定规则验证/README.md)。历史留出段是回顾验证，尚无真正新数据的前向确认；不据此更换原公式或继续挑选参数。

## 未验证的边界与项目选择

| 情形 | 本项目的行为 | 官方行为是否确认 |
| --- | --- | --- |
| 不足 13 次变化 | 返回 `None`，不使用部分窗口 | 未确认 |
| 13 次变化全为零 | 返回 `None`，不擅自填 0 或 50 | 未确认 |
| 缺失收盘价 | 中断窗口，重新积累完整的 14 个收盘价 | 未确认 |
| 恰好等于 30 / 70 | 归中间区，按严格 `<30` / `>70` 判断 | 未确认 |
| 当日未收盘 | 按提供的当前价计算，不冒充收盘确认 | 截图为盘中值 |

没有未来数据引用；当根价格变化时，当根指标值也会变化。复权设置、历史价格修订同样会影响历史结果。
绘图柱宽、长图中约 3px 的填充偏移、颜色常量及同花顺内编译行为均未实测。
