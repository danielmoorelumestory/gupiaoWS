# 固定三规则验证

第一轮研究已完成。原公式13周期、阈值30未寻优；新增的解释功能不改变原指标值。

优先阅读 [结果报告](结果报告.md)。结论是：**主口径没有支持“重返30且当天上涨”优于单纯重返30，暂不升级默认规则。**

## 已交付

- 规则A：首次跌破30。
- 规则B：从低于30回到30及以上。
- 规则B+：规则B且当日连续调整价上涨。
- 10只事先指定的ETF，9只通过审查。510500因604根调整价不一致隔离，未换入别的标的。
- 收盘信号、次交易日开盘入场，持有5/10/20个交易日；往返0/10/30基点成本情景；逐规则去掉重叠持仓事件。
- 开发段为2021年前，历史留出段为2021年起，统一截至2026-11-10。9只ETF各自可得历史不同，完整覆盖日期在报告中。
- 主检验固定为：10日、往返10基点，ETF等权B+减B。

主差额 `+0.030` 个百分点，95%日期块自助法区间 `[-0.171,+0.240]` 个百分点，改善方向4/9；不满足事前支持条件。

历史留出段三规则的单次净收益等权均值约为 A `-0.09%`、B `+0.18%`、B+ `+0.21%`。这是事件收益，不能当成年化或完整组合收益。三者主口径净超额均值均没有超过同ETF同分段的无条件持有期毛收益参照。

## 数据与收益口径

`data/raw/` 保留86个公开响应的压缩原文；`data/*.csv.gz` 是9只通过审查的规范化输入，来源与哈希在最终审查文件中。
份额因子s、累计现金u来自新浪，逐日 `raw_close*s+u` 与东财或腾讯后复权价格在事前指定容差内核对；9只纳入标的没有超容差记录。这是第三方报价一致性检查，不是逐条官方分红公告审计。

信号用因子截至当日的连续价。收益单独使用实际开收盘与份额、现金权益：入场后份额变化逐日记账，分红以除息经济权益记现金/应收，不强制再投。入场当天已除息的分红不送给新持有人。收益口径与原App每只ETF的前复权未逐一核验。

净收益按初始资金扣固定往返成本；成本情景不是券商报价。基准是同ETF、同分段、同持有期无条件次日开盘至期末收盘的毛收益均值，只是市场漂移参照，不是组合。

## 离线复现

在本目录运行，只需Python标准库，以下不联网：

```sh
python3 -m unittest -v test_study.py
python3 run_study.py
python3 verify_study.py
python3 render_report.py
python3 verify_bundle.py
```

`run_study.py` 读取已存文件，按固定随机种子重算所有规则、持有期、成本和日期块区间。重新获取数据才运行 `prepare_panel.py`；重新取数会产生新的审查版本，不应覆盖后声称还是同一份历史输入。

`verify_study.py` 已对5048个保留事件检查输入哈希、Fraction精确信号、次开盘成交、持有长度、分段清除和逐规则不重叠，并用独立的逐日份额/现金账本核对收益与MAE。最大误差约4.45e-16，属于浮点舍入量级。

## 输出与限制

- `results/summary.json`：主结论、输入哈希、日期块区间和限制。
- `results/per_etf.csv`：全部逐ETF规则/持有期/成本结果。
- `results/aggregate_common_all3.csv`：只比较三规则均有事件的共同ETF，避免不同样本混为一谈。
- `results/primary_B_plus_vs_B.csv`：主比较的逐ETF差额。
- `results/paired_filter_diagnostic.csv`：同一批B事件里保留和剔除部分的未来结果；不把当日没涨的信号先验地叫作错误信号。
- `results/events.csv.gz`：全部5048个保留事件，可追溯信号、成交日期、收益和最大不利波动。
- `results/verification.json`：独立账本复核。
- `bundle-manifest.json`：本研究包的文件完整性清单。

已见过的近期市场不是真正未见样本；当前仍上市面板存在存活者偏差，不同ETF同期相关。没有盘口成交、最小手数、限价排队、完整仓位、空仓收益及年化组合绩效。日期块区间也不保证覆盖所有市场周期依赖。未来数据前向确认尚未发生，因此这轮不能据此宣称优化有效。
