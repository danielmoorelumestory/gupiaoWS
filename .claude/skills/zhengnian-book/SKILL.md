# 《正念投资》书稿工作规范

这本书写给普通投资者，立场是：先配置、再平衡；不预测宏观、不做短线；只做自己看得懂的企业研究；给投资设边界。读者会拿真钱照着做，所以**可信度比文采重要**：一个说不清来源的数字，比一句平淡的话更伤书。

## 开工前先做三件事

1. 读 `book-慢即是快/README.md` 和 `优化待办-下一步.md`。这个目录可能被另一轮修订同时改动（审稿建议、修订记录、专题、附录H等都是它的产物），不要覆盖别人刚改的内容；改前用 Read 读一遍目标文件当前内容。
2. 查 `附件-数据/数字核对表.md`：要用的数字是否已登记，状态是 `已核/接口/待核/教学` 中的哪一种。`待核` 的数字不得在正文写成确定事实。
3. 确认任务落在哪个文件：章节 `第N章-*.md`，附录 `附录X-*.md`，开篇 `开篇-*.md`，全书结构 `全书大纲.md`。章号以大纲和 `BusinessWeb/src/pages/FirstBook.tsx` 的 `PARTS` 为准，二者必须一致。

## 写一章（或改一章）的结构

每个方法章尽量走完这条判断链，读者才知道“凭什么这样判断”：

**一句话结论 → 机制 → 推演（数字可复算）→ 反例或失效条件 → 来源与更新频率 → 行动清单。**

- 开头的“本章一句话”写结论，不写铺垫。
- 先讲案例，后引经文；每章最多引一句《道德经》，且不要和 `附录B`、其他章末的引语重复（引用前 grep 一下）。
- 工具章（配置、估值、网格等）以“规则＋清单”为主，不硬套“经文—案例”。
- 语气像朋友喝茶聊天，不用学术腔；一段尽量不超过240个字符。
- 全书只保留一套决策记录字段（见第37章37.4的母版），新增清单时引用它，不另造字段名。

## 数字、案例与口径（最容易出事的地方）

- **不编造**。没有来源的数字，不写；教学用的假设数字必须明说“教学假设，非真实公司”，并能用公式复算。
- 真实案例标注“历史案例，非投资建议”，并说明是**事后口径**（当时的投资者看不到的数据，要写明）。不推荐具体股票，不承诺收益，不给个人化的买卖建议。
- 同一指标要带**起点和终点**。指数用价格指数时写明“不含分红”；年化折算年交易日：A股243、美股252、港股247。完整对照见附录F“数据口径对照表”，脚本 `附件-数据/口径对照.py`。
- 新引入的真实数字，当场登记到 `数字核对表.md`（编号、数字、章节、来源、报告期、口径、状态）；取数或回测的脚本放进 `附件-数据/`，让别人能复现。
- 接口数据（腾讯行情、财务指标接口）状态只能写 `接口`，要改成 `已核` 必须对着年报或交易所原文。该行情接口的ETF前复权数据2021年前不可靠，不要用。
- 对结论不利的实证也要写（例如半仓＋网格没有稳定超额、“涨多了就卖”不可靠）。写出来比删掉更可信。
- 暂时补不出的案例，保留 `[待补]` 或 `[待核]`，不要用推测填充。

## 去AI腔（配合 humanizer）

写完或改完一章，可以调用 `humanizer` 过一遍，但用它之前要知道三件事：

- 它的规则以英文为主，**只改文风，不能改事实**：数字、公司名、年份、引语、链接、表格里的数据一律保持原样，只动叙述性文字。用它的“文件模式”并先说明这一点。
- 中文里最常见的腔调要重点查：满篇“不是……而是……”的对比、每节一句的总结式收尾、强行凑三条、破折号和冒号滥用、给每个词加粗、“最重要的”“核心”“关键”之类的拔高词。
- 改完要对照原文，确认没有增删任何事实性内容；有疑问以原文为准。

## 页面渲染的限制（写 Markdown 时要避开）

`BusinessWeb/src/pages/FirstBook.tsx` 里的渲染器是自写的轻量版：不支持嵌套列表（多层缩进会被拉平），含 `*` 的文字会和粗体冲突（如 `f*`、`*ST`，改用 `f★`、“带星号的…”）。表格、引用块、`**粗体**`、`*斜体*`、行内代码可用。

## 做完之后：登记与发布

1. 把改动写进 `修订记录-第N轮-日期.md`（用最新的一份追加），并更新 `优化待办-下一步.md` 里对应条目的状态。
2. 章节改名或新增时，同步改 `全书大纲.md`（含总目录）和 `FirstBook.tsx` 的 `PARTS`（`title`、`file`、`status`）。
3. 发布流程见 `references/publish.md`。**只提交书稿相关的文件**，工作区里还有用户自己的未提交改动，不要碰。

## 反复出现的坑（来自这本书的历史）

- 改章号要同步：大纲、`PARTS`、文件名、章内“第N章”引用、附录B的卡片对应章号。改完 grep 一遍旧章号。
- 同一指标出现多个取值（如沪深300年化2.5%／4.1%／-1.1%），说明起点不同；每次出现都带起点终点。
- 事后挑选的例子（美的、招行、茅台）只能用来演示“怎么分析”，不能写成规律。
- 未复权价格遇到送转会失真（宁德时代就是例子），不能直接和历史每股收益相乘。
