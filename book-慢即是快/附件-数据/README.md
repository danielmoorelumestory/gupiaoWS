# 附件-数据：数据来源与口径

- 数据：沪深300(sh000300)、创业板指(sz399006)、中证红利(sh000922)、上证国债(sh000012)、中证500(sh000905)的日线收盘价，起止约2008年至2026-09-30。
- 来源：腾讯行情接口（web.ifzq.gtimg.cn fqkline），由 `fetch.py` 抓取。
- 口径：股票采用价格指数，不含股息再投资；上证国债指数按编制方案包含全价与利息再投资，不能一概称为不含利息；用于第6章6.5节（自然年涨跌）与第11章11.4.2节（滚动窗口回测）。
- 核对：沪深300年度涨跌幅（2013–2025）与公开数据逐年核对一致（如2014 +51.7%、2018 -25.3%、2022 -21.6%）。
- 不使用：同一接口的ETF前复权日线在2021年前与指数明显不一致（如沪深300ETF的2014年涨幅显示为+81.5%），已弃用，未入库。
- 脚本：`yearly.py`（年度表）、`rolling.py`（滚动窗口回测，依赖 `../附件-模拟脚本/grid_sim.py` 中的策略函数）。
- 局限：2026年数据为截至9月30日；回测未计入跟踪误差、买卖价差、溢价与税费差异；滚动窗口相互重叠。
- `trend_dca.py`：趋势跟踪（只做多，120/200日均线）与月度定投的滚动窗口回测，用于第6章6.3.2节；成本0.05%单边，现金不计息，均线信号当日收盘判断、次日生效。
- `pe_decomp.py` 与 `*_raw.csv`：美的集团、招商银行、贵州茅台的未复权日线收盘价（腾讯行情接口），用于第13章13.2节的“价格=每股收益×市盈率”拆解；每股收益取公开财务指标。宁德时代因资本公积转增导致未复权价格与历史每股收益不可比，已弃用。

## 第9章回测口径修订（2026-10-03）

`ref_plan.py` 改为实际日期计算CAGR，五个市场日期并集估值，休市使用最后可用价格；月末收益计算相关系数与年化波动。可在任意目录运行 `python3 /完整路径/ref_plan.py`。

样本为2020-07-27至2026-09-30，约6.177年，74个月收益观测。它仍是原币种收益合成的教学组合，未加入汇率、权益分红、实际产品跟踪误差。第五轮核对上交所000012编制方案第2页：公式包括全价、债券利息及再投资收益；它仍不等于实际纯债基金。再平衡未模拟休市和时差造成的成交延迟。

其他脚本的年化约定与数据来源尚待统一核验，不因第9章复算而视为全书数据均已核实。
- `口径对照.py`：生成附录F“数据口径对照表”（同一指数在不同起点下的年化、波动、回撤；按市场折算年交易日）。

## 第十四轮：固定文件版本，区分计算与核验（2026-10-04）

`数据快照清单.csv` 登记本轮现有CSV与计算脚本的大小、日期范围及SHA-256。登记日期是2026-10-04，不是原抓取日期；原抓取时间与原始接口响应未完整留存，不追补虚构记录。此清单是文件索引，不是备份，保留本轮文件副本才能支持后续复算。

复算时从本目录运行脚本，并保留输出、Python及依赖版本。`pe_decomp.py` 的EPS为手工输入，具体值可在脚本中查看，原始报告核对状态见数字核对表。清单包含该脚本，能定位输入版本，但不代表输入已核实。

后续新增或更新数据，逐批登记：来源URL与参数、抓取时间、原始响应、清洗规则、价格与分红口径、缺失或异常处理、脚本版本及独立核验对象。财务数据另记报告发布日期、报告页码、单位和基本/稀释口径。新批次另存目录，不能覆盖原版证据。

未完成事项：全库原始响应归档、抓取时点追溯、关键财务输入的逐项原始报告核验、跨来源抽查及全书年化口径统一。现有年度涨跌幅核对与作者复算不能替代这些工作。

## 第十五轮：全收益指数（2026-10-05）

新批次存放在 `第十五轮-全收益/`，不覆盖原价格指数文件与脚本。

- 数据：沪深300全收益（H00300）、中证红利全收益（H00922）、中证500全收益（H00905）及对照用价格指数（000300、000922），来自中证指数有限公司官网接口；创业板R（399606，深交所全收益）来自腾讯行情接口；标普500全收益（^SP500TR）与价格（^GSPC）来自Yahoo Finance。抓取脚本 `fetch_tr.py`，原始响应在 `raw/`，抓取时间、URL与行数在 `抓取记录.csv`。
- 清洗：中证数据含节假日行（收盘沿用前值），计算时按腾讯价格序列的交易日剔除；Yahoo时间戳按纽约时区转为日期。
- 跨来源抽查：中证官网沪深300价格与腾讯数据，共同交易日中仅2011-12-13至15三天偏差超过0.1%；Yahoo ^GSPC与腾讯 us.INX 共同4716日中仅3天偏差超过0.1%。
- 脚本：`tr_single.py`（单项价格对全收益，第3章、附录F）、`tr_rebalance.py`（第8章，由 `rebalance.py` 复制只换数据）、`tr_ref_plan.py`（第9章，由 `ref_plan.py` 复制只换数据）、`tr_risk_contrib.py`（第9章风险贡献）。每个脚本先确认用价格数据能复算出原结果，再换全收益数据。
- 局限：全收益指数未计基金费用与跟踪误差；恒生科技没有取得全收益序列，第9章中仍为价格指数；第6、11、12、14、17、34、35章及 `口径对照.py` 仍为价格口径，待重算。
